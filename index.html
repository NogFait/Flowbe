Método Flowbe

Menos humo. Más proceso.

Una web profesional no sale de adivinar colores y tirar bloques. Primero se define objetivo, alcance, contenido y materiales. Después se diseña, se desarrolla, se revisa y recién ahí se publica.

1

Brief y alcance

Definimos qué necesita el negocio, qué secciones entran y qué queda afuera para evitar malentendidos.

2

Propuesta y anticipo

Enviamos la propuesta, se confirma el proyecto y se abona el 50% para reservar el inicio.

3

Materiales

El cliente entrega textos, fotos, logo, datos de contacto, horarios, redes y cualquier contenido necesario.

4

Diseño y desarrollo

Diseñamos, desarrollamos y compartimos una URL de previsualización para revisar antes del lanzamiento.

5

Aprobación y lanzamiento

Con la versión final aprobada, se abona el 50% restante y publicamos el sitio.

Mensualidad

La web no queda tirada después de publicarla.

La mensualidad cubre la operación básica del sitio para que no tengas que pelearte con hosting, dominio, backups o cambios menores.
